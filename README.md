PostgreSQL Business Analysis
About the project
Practical SQL exercises developed using PostgreSQL, focused on business analytics, sales performance, customer behavior and commercial analysis.
Database
Fictional distribution company with the following tables:
- Customers
- Products
- Orders
- Order Items
- Inventory Movements
Skills demonstrated
- SQL queries and filtering
- INNER JOIN and table relationships
- Aggregations and GROUP BY
- Subqueries and CTEs
- Window Functions
- RANK and DENSE_RANK
- LAG and monthly comparisons
- Business performance metrics
Challenges
1. Sales aggregation
2. Customer sales analysis
3. Subqueries and average sales
4. Monthly sales analysis
5. Product performance
6. Product ranking by category
7. Customer sales concentration
8. Monthly customer sales trends
Tools
- PostgreSQL
- SQL
- DBeaver
